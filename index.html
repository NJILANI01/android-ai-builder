Comment ça marche

Prompt → Flowchart → Code.
En 3 étapes.

ÉTAPE 01
✍️

Décrivez votre application

Saisissez une description en langage naturel dans le panneau latéral d'Android Studio.

"Une app de gestion de tâches
avec login, liste, ajout/
modification et notifications."
ÉTAPE 02
🔀

Affinez le flowchart

Claude génère un diagramme de navigation. Affinez-le en langage naturel jusqu'à satisfaction.

flowchart TD
  A[Login] --> B[Dashboard]
  B --> C[Liste tâches]
  C --> D[Ajouter tâche]
ÉTAPE 03
⚡

Générez et injectez le code

Kotlin + XML complet, architecture MVVM, injecté directement dans votre projet ouvert.

✓ MainActivity.kt
✓ TaskListFragment.kt
✓ TaskViewModel.kt
✓ nav_graph.xml

Construit par un développeur, pour les développeurs.

Android AI Builder est un projet indie né d'une frustration simple : pourquoi le prototypage Android prend-il encore des jours alors que l'architecture est souvent prévisible ?

Ce plugin est le fruit de 1 à 2 ans de développement Android, combinées à l'émergence des LLMs capables de générer du code structuré et maintenable.

Pas de VC. Pas de team de 50 personnes. Juste du code, des utilisateurs, et une conviction.
